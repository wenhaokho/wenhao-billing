# Task 33: Customer balances

Implemented GET `/api/v1/customers/balances` using persisted-admin session checks, a generated sqlc aggregation and a Huma registration. Aggregates open, sent and partial non-template invoices with positive balances and customer IDs by customer and currency; overdue uses the local current date and strict `<` comparison. Numerics are returned as exact PostgreSQL decimal strings. Invalid nonfinite results fail with a sanitized 500. No business_id column exists in the current schema.

Tests: `TestCustomerBalancesPostgres` first failed with 422 because `/balances` was interpreted as a customer UUID before route registration, then passed. It seeds separate disposable Goose databases and compares actual Go and FastAPI HTTP data as unordered groups; covers multiple customers/currencies, the three open statuses, draft/paid/void statuses, templates, null customer, zero/negative balance, overdue/today/future/null due dates and zero aggregation. It checks missing/tampered/deleted/nonadmin credentials, no-store, database snapshots, nonfinite stored numeric rejection, empty `[]`, OpenAPI array/security/error statuses. The Python dependency override authenticates the differential request; Go auth is tested separately. Data snapshots encompass invoices, customers, users and were compared immediately after HTTP reads. Python and Go use the same system local date; the test generates dates from the clock and should not be run exactly across midnight.

Five independent generated-SQL mutations failed for the expected result mismatch and were restored: include draft status, include templates, include nonpositive balances, change overdue `<` to `<=`, and group additionally by status. sqlc was generated with `go run github.com/sqlc-dev/sqlc/cmd/sqlc@v1.29.0 generate`. Limitations: the differential fixtures cover selected statuses rather than every arbitrary persisted status. No deterministic injected clock: implementation and Python both use local wall-clock date, so midnight rollover is a test and in-flight query boundary. OpenAPI field schema properties are generated from Go types but not individually asserted. No production, provider, email or Python source changes.
