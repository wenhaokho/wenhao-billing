# Task 18 report

Implemented `internal/email`: `Sender.Send(context.Context, Message) error`, `Config`, and byte-backed attachments. `New` selects Resend over SMTP, or a disabled sender returning `ErrDisabled`. Delivery is synchronous; `nil` means the provider accepted the message, not that it reached the recipient. `ErrDelivery` hides provider responses and transport details; cancellation and deadline errors remain distinguishable. No messages or credentials are logged. SMTP uses STARTTLS with certificate verification and requires it for authentication; unauthenticated plain SMTP is allowed. Message addresses and headers are validated to prevent injection. No application wiring, migrations, or external delivery was added.

Resend uses official `resend-go/v2` v2.28.0. Its attachment encoder sends byte arrays rather than Python's base64 string; content is preserved and the SDK explicitly implements this format. SMTP MIME includes plain text, optional HTML and attachments. The package takes already-separated CC addresses rather than parsing Python's comma/semicolon input. Callers must populate sender settings; no environment loader or application integration is included. Default timeout is 15 seconds (Python SMTP used 10); caller may set a positive timeout. HTTP Resend URLs require HTTPS except loopback HTTP for local testing. SMTP authentication without TLS is rejected even though Python permitted it. Provider details are intentionally suppressed, including HTTP status and retry hints.

Tests: `go test ./internal/email -count=1` exercises disabled delivery, Resend precedence/auth/payload/attachments, response failures, redaction, cancellation and timeout, invalid configurations, captured plain SMTP delivery, generated-certificate STARTTLS, AUTH PLAIN success and rejection/redaction. All services are disposable local test servers. Initial test-first run failed to compile because the new package did not exist; it passed after implementation. The SDK attachment test initially revealed the array encoding and was adjusted to its actual contract.

Mutation command `python3 /tmp/task18mut.py` independently altered and restored the source. Suppressing Resend precedence failed `TestResendPrecedenceAndPayload`; permitting credentials without TLS failed `TestValidation`; returning success on a provider error failed `TestErrorRedactionAndCancellation`; returning the raw SDK error failed that test with the injected secret visible. An initial validation mutation survived because the test also had an invalid sender; adding a valid sender exposed the guard. Limitations: no live provider was contacted. SMTP tests cover one successful STARTTLS/AUTH PLAIN exchange and a rejected authentication, but do not exhaust protocol errors, MIME client interoperability, SMTP timeout/cancellation behavior, or certificate rejection. No retries, idempotency, delivery status tracking, or outbox are provided. Message MIME encoding is independently generated, so its exact bytes differ from Python. No end-to-end integration with the future application configuration is claimed.

## Review fixes

SMTP MIME now folds base64 at 76 characters, encodes and folds long subjects into UTF-8 encoded words, formats address display names, and rejects a generated physical line over 998 octets. Large attachment/text and ASCII/Unicode subject tests parse and decode the resulting multipart message and compare the original bytes; physical message lines are checked against 998 and base64 lines against 76. Exception: exceptionally long individual address or MIME parameter lines are rejected rather than folded, and MIME header folding beyond these cases is not exhaustive.

After the server accepts DATA with 250, QUIT is best effort and its error cannot be returned as delivery failure. `TestSMTPQuitFailureAfterAcceptance` covers both a 500 reply and dropped connection. Acceptance still does not guarantee delivery; if the connection is lost before the server's DATA response is received, acceptance is inherently ambiguous. `TestSMTPTimeoutAndCancellation` covers a stalled SMTP greeting and `TestSMTPStartTLSAuth/cert-reject` verifies an untrusted certificate is rejected before authentication. Initial focused tests failed on line length and both QUIT cases, then passed after the fixes; an added long ASCII-subject test exposed unintended spaces in folded unencoded chunks and drove encoded-word correction.
