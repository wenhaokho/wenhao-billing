# Task 21: Customer soft deactivation

Implemented DELETE `/api/v1/customers/{customer_id}` with a sqlc-generated parameterized UPDATE returning the full row. The handler authenticates with the shared persisted-admin check, locks and rechecks that user in the update transaction, converts the returned row before commit, and only returns it after a successful commit. It preserves the customer and does not issue provider calls or invent a business_id. Huma describes the path parameter, response, security and errors. No Python source, schema or migration changes.

Tests were written first: the targeted tests failed with 405 and missing DELETE OpenAPI before implementation. `go run github.com/sqlc-dev/sqlc/cmd/sqlc@v1.29.0 generate` generated the query.
